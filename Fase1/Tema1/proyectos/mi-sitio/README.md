Repositorio de ejercicios del Tema 1 «Entorno y terminal» de la ruta de estudio Full Stack. Contiene la carpeta mi-sitio, creada solo con comandos de terminal: la primera página HTML con su hoja de estilos enlazada, la carpeta de imágenes y este README con la evidencia del trabajo.

Git: 2.56.0.windows.2
Terminal: PowerShell 5.1
Navegador: Google Chrome 155.0.8059.85


## Comandos base utilizados

Comando | Qué hace | Ejemplo real ejecutado |
------- | -------- | ---------------------- |
`pwd` | Muestra la carpeta actual | `pwd` |
`ls` | Lista los archivos de la carpeta | `ls` |
`cd`| moverse entre carpetas | `cd C:\Users\alejo\Downloads\Programación\Fase1\Tema1\proyectos` |
`mkdir`| Crear una carpeta | `mkdir mi-sitio` |
`New-Item`| Crear un archvio vacío | `New-Item index.html`|
`cp`| Crear copias de un archivo | `cp index.html imagen.html`|
`mv`| mueve o renombra un archivo | `mv imagen.html img\imagen.html` |
`rm`| Elimina un archivo | `rm copia.html` |
`cat`| Mostrar el contenido en la terminal | `cat README.md` |

Estos fueron los comandos que utilicé para dejar creado todo el arbol con estructuras e iba revisando que iba pasando


Para la revisión en vivo en el DevTools realice los pasos que aparecen en la guía, cambie el estilo del titulo desde elements, verifique que tanto el index como el css/estilos.css dieran el codigo 200, cambié la carpeta css a otro nombre y al recargar el navegador salio en el network (failed)net::ERR_FILE_NOT_FOUND en la columna status y en console salía un error GET que aun no entiendo, volvi a cambiar el nombre de la carpeta usando mv css2 css, recargué la página y ya todo funcionaba con normalidad sin errores en consola y en el network status 200 que indica que la ruta esta bién.
