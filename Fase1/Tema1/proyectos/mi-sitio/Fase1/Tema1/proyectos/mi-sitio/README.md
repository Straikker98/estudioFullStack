Pwd: Muestra dónde estás parado - Lo use para ver la carpeta donde estaba ubicado para iniciar
ls: Lista archivos - Lo use para ver los archivos que tenia en esa carpeta
cd: entra  a una carpeta - Lo use para moverme entre carpetas
mkdir: crea una carpeta - Cree todo el arbol de carpetas
touch / New-Item: crea un archivo vacio - crear los archivos vacios como el index.html
cp: crea una copia de un archivo - cree una copia del index.html con el nombre imagen.html
mv: mueve o renombra un archivo - moví el archivo imagen.html a la carpeta img
rm: elimina un archivo - Ralmente no lo usé
cat: muestra el contenido en la terminal - Vi el contenido del README
